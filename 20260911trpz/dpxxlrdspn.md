# 结核性盆腔炎的那些事儿

> 更新时间：2026-09-11 (UTC+8)

责任编辑：马淳
**前言**

说起结核，大多数人的第一反应是肺结核，其实，结核杆菌其主要的传播途径之一为经血液传播，因此，全身的结核病灶均有可能经血行播散感染盆腔，引起不孕、月经失调等。今天，我们就来聊聊结核性盆腔炎的那些事儿。

疑问权威回应
Q:我从来没有过咳嗽、咯血、午后低热等结核的特征性表现，我为何会得结核性盆腔炎呢？
结核感染有些隐匿性，约40%的结核患者是没有症状的，且生殖器结核潜伏期较长，可达1-10年，多数患者在发现生殖器结核时，原发病灶多已自愈或治愈。

Q:盆腔结核为何会导致不孕呢？
结核杆菌感染肺部后，大约1年可感染内生殖器，由于输卵管黏膜利于结核杆菌的潜伏感染，结核杆菌首先会感染输卵管，几乎所有的生殖器结核均会感染输卵管，导致输卵管黏膜破坏，管腔内充满干酪样坏死组织，管壁僵硬，伞端闭锁，从而丧失运送卵子、受精卵的功能，导致不孕。病情进一步发展，结核会经由输卵管感染宫腔，导致子宫内膜受到结核杆菌不通程度的破坏且不可逆。严重时宫腔内膜消失、瘢痕化，表现为经量减少、闭经、宫腔粘连等。

Q:我要做输卵管疏通术，就因为我得过肺结核或淋巴结核，医生为何要切除我的输卵管？
结核性输卵管炎患者的输卵管造影片常呈典型的串珠样改变或管腔细小且僵硬，因此，术前大夫对输卵管情况会有初步的评估，若高度可疑输卵管结核，是建议行输卵管切除的，这是为何呢？

其一，输卵管一旦经结核破坏是不可逆的，保留下来几乎无自然妊娠可能；

其二，因输卵管管腔黏膜适合结核杆菌生存，输卵管管腔易藏匿结核杆菌，且有进一步向宫腔蔓延、感染宫腔可能；

其三，因无自然妊娠可能，需行试管婴儿助孕，超促排卵过程中产生的超生理剂量的雌激素会导致血管通透性增加，藏匿于输卵管中的结核杆菌易播散至全身感染；

其四，经试管婴儿助孕后成功妊娠者，因孕期处于免疫抑制状态，易导致体内潜伏的结核病灶死灰复燃，严重者危及母胎生命。

由此可见，结核对女性的健康及生育影响极大，对确诊或高度可疑结核者，建议结核病院行结核相关检查后再行辅助生殖助孕，切不可存侥幸心理！
