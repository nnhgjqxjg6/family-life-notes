# 你和那些易孕的姐妹们到底差别在哪呢？怎么样才能补短板呢？

> 更新时间：2026-09-16 (UTC+8)

生活中，有这么一类人，她们没有刻意去怀孕，却顺其自然就有了，有些人呢，却很难怀孕。就比如同为工作压力大、生活不规律的明星，高圆圆、谢娜、范玮琪等，备孕多年才顺利生子;而昆凌、张柏芝、贾静雯等，却一胎接一胎地生(关键是生完身材还那么好)!

那么，这是否就是传说中的“易孕体质”呢?易孕和难孕，到底差在哪里呢?下面，就从生殖医学角度来讲讲，我们的生育力到底是由什么决定的。

**生育力好不好，先看看卵巢储备功能**

说到生育力的量化指标，那卵巢储备可是当之无愧的“大佬”了。我们都知道，女性的卵巢储备是定量的，随着时间的流逝，卵泡会减少、卵子质量会变差、卵巢功能也会连年衰退……而卵巢的衰老，又与我们的生活习惯、所处的环境、自身的情绪等，都有直接的关系。

要想知道卵巢储备功能好不好，目前临床上最常用的指标有卵泡刺激素(FSH)、黄体生成素(LH)、雌二醇(estradiol,E2)、窦卵泡计数(AFC)和抗苗勒管激素(AMH)这几项。要娃的难易程度，基本是由它们决定的。

**AMH**

AMH是一种主要由卵泡颗粒细胞合成分泌的小分子激素，在整个月经周期中水平相对稳定，随时可以采集血样做检测，能及时反映卵巢储备的变化趋势。

**根据AMH水平，女性从出生到衰老可以分为四个阶段：**

●儿童期(0～10岁)：原始卵泡储备增加明显，AMH均值为3.09±2.91mg/L，随年龄增加而升高
● 青少年期(11～18岁)：卵巢储备达高峰，AMH均值为5.02±3.35 mg/L
●育龄期(18岁以后)：卵巢储备开始下降，AMH均值为2.95±2.50 mg/L，随年龄增加而降低
● 耗竭期(50岁以后)：AMH均值0.22±0.36 mg/L，与年龄不再相关金风和煦，万物复苏。百芳发而幽香逸，春鸟还而鸣声碎。

PS：由于在青春期前女孩体内AMH水平也较高，因此AMH仅在临床用于评估25岁以后的卵巢储备功能。

**AFC**

除了AMH，AFC也是预测卵巢储备功能的一个重要指标。AFC是超声下观察到的两侧卵巢的总窦卵泡数(φ2~10mm卵泡)，一般在早卵泡期(月经第2~4天)进行检查。

若B超显示卵巢中仅有<5~7个窦卵泡，甚至少至2~3个，就表明卵巢储备功能已明显下降。但它的准确性受个体肥胖、医师技术、超声机器型号等因素的影响，不能单独作为生育力的判断依据。

**FSH**

FSH即卵泡刺激素，参与调控人体的发育、生长、性成熟、以及生殖相关的一系列生理过程，主要作用是促进卵泡的发育和成熟。它是基于卵巢激素对垂体分泌的反馈机制，属于间接反映卵巢储备的指标。

FSH升高，即反映卵巢储备功能下降。血FSH的浓度，在排卵前期为1.5～10mIU/ml，排卵期为8～20mIU/ml，排卵后期为2～10mIU/ml;基础状态下数值<8为正常，数值>12则表示卵巢出现衰退迹象。

**那AMH很低、FSH很高，还能生吗?**

其实，病人不会按照教科书的描述来生病，无论是书本、指南还是随机临床对照试验，都不能涵盖所有病例。虽说AMH和FSH水平，对预测生育力的价值很大，但活人怎么能被死的数据吓到呢!有那功夫天天纠结数字指标，还不如切实做点啥。

对于卵巢功能差的姐妹，不要过于纠结FSH有多高，AMH有多低，更重要的是关注自发月经。毕竟我们无法计算每个困难病人怀孕的成功率，在你身上成功了就是1，失败就是0，我们要做的，就是穷尽各种方法做最合理的措施，在当下做到极致，无怨无悔。

首先得寻求专业生殖医生的帮助，再积极配合医生进行个体化的促排卵治疗方案，如随时调整GnRH拮抗剂的剂量、黄体期促排卵方案、微刺激方案、冻胚移植等。

至于生育力的影响因素，“年龄”我们就不说了，早已是老生常谈。今天为大家罗列了几点保护卵巢的方法，简单易行，坚持去做，总比杞人忧天要好得多!

1. 作息规律，保证充足的睡眠，尽量每晚11点前睡觉。

2. 久坐不动不利于血液循环，建议坐1小时就起来活动活动。

3. 每周进行3次左右的体育锻炼，慢跑、快走、游泳、跳绳、羽毛球、包括广场舞，都是很好的锻炼方式，有助于全身各器官系统的功能健康与协调。

4. 
多吃些补肾健脾的食物，如五谷、海参、糯米、山药、薏仁等;多吃些疏肝理气、宁心安神的食物，如大枣、柚子、陈皮等;多吃些优质蛋白，如肉类、鱼类、蛋类、薯类、奶制品、豆制品等;多吃新鲜的蔬菜水果。

5. 尽量避免人工流产和人工终止妊娠;避免过度减肥，尤其是节食减肥。

6. 日常生活中保持平和的情绪和心态，少生气，少悲观，少焦虑……

备孕路上的你，如果已经遇到了卵巢功能减退、内膜质量不佳、输卵管不畅、宫腔微环境不好、试管反复失败、甚至是老公精液质量不达标等难题，那你就把自己交给专业生殖医生，不要自己瞎折腾。
