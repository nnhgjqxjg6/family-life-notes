# 宝宝频繁吐泻别慌！一文教你正确应对方法

> 更新时间：2026-09-17 (UTC+8)

近期门诊上，腹痛吐泻伴或不伴发热的患儿增多。其中以急性胃肠炎的宝宝较多。原因症状有哪些呢？哪些情况需要及时就诊呢？下面就来和大家聊聊这些问题。

**01**

**什么是急性胃肠炎？**

是指胃和肠道黏膜的急性炎症，通常由感染、食物中毒或其他因素引起。**其主要症状包括呕吐、腹泻、腹痛等，病程较短，多数患者在数天内恢复。**原因有病毒感染（最常见的肠道病毒感染，如诺如，轮状等，每年11月到次年的2-3月为高发期），细菌感染 寄生虫感染（极少见）还有非感染因素（饮食，药物等）。

**02**

**急性胃肠炎的症状是什么？**

腹痛：多为阵发性绞痛，位于上腹部或脐周。若有右下腹疼痛，或是转移性腹痛要要警惕阑尾炎的可能哦。

腹泻：大便水样，蛋花样，或者糊状，甚者可能带有黏液或血丝，次数几次至十多次不等 。

呕吐：频繁呕吐，可伴有恶心，常为胃内容物，或水样物质，甚者胆汁样物。如出现咖啡样物质，或肉眼可见血性分泌物要及时消化内科就诊。

其他症状：伴或不伴发热、乏力、头痛、肌肉酸痛等。

及时就医：**若出现频繁呕吐，进食困难或无法进食，精神萎靡， 尿量明显减少、眼窝凹陷等情况，需要及时就诊。**医生会根据病史，查体情况，完善血常规，腹部B超，大便常规 ，心肌酶等相关检查。

**03**

**急性胃肠炎治疗：**

1、口服补液盐Ⅲ（ORS）预防纠正脱水，严重脱水者需要静脉补液。

2、对症治疗（维生素B6止吐，蒙脱石散止泻，益生菌调节肠道等处理）

3、抗感染治疗，细菌感染加用抗生素，病毒感染主要还是对症处理。

**04**

**居家护理需要注意那些**

1、注意手卫生：勤洗手，尤其是饭前便后。

2. 饮食安全：避免食用不洁或未煮熟的食物，确保饮用水干净。尽力食用易消化，清淡饮食。减少与吐泻患者的接触，防止交叉感染。

3. 接种疫苗：如轮状病毒疫苗。

4、注意休息，同时要密切观察小便，精神，皮肤弹性等情况，警惕脱水。如有异常及时就医。

宝宝的健康无小事，护理宝宝更要从小事做起。
