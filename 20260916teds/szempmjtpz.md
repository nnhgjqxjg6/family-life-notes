# 去医院怎么查不孕？

> 更新时间：2026-09-16 (UTC+8)

导读

在医院经常看到不孕家庭兜兜转转十几年都没有好好的治疗过，终于来对了医院才发现已经错过了最佳怀孕时机，治疗困难，一旦怀孕风险也会增加。

如果试孕一年没有怀孕，应该可以诊断不孕症。

而一旦诊断不孕症，首先应该找到对的医院。

**哪些是不对的医院？**
**某度竞价排名的某系医院和传统医学。**

某系医院确实坑人，曾经有个患者，他老公在某男科医院检查精液，严重少弱精子，医院说需要治疗，一下子开了数种药物，几千元。后来不放心再次来我这里复查，结果完全合格，而这位患者经过促排卵后很快就怀孕了。某系的医院显然就是骗患者花钱而已。

很多不怀孕的女性常常被家长拉着去看传统医学，吃很多药物，什么调经促孕丸啥的，听起来名字不错，但实际效果如何就不知道了。很多人来我门诊看不孕症时，在叙述就诊经历的过程中，我常常让他们省略在传统医学的过程，因为这对我们一点参考意义都没有。

**不孕症该怎样检查？**

**性生活**

首先先看看夫妻间的性生活频率是不是足够，现代人生活压力大，性福程度不够，这是很多人不孕的原因。
**精液常规**
其次是要查男性的精液常规。男性原因占了不孕原因的1/3，很多男性羞于检查，我常常对患者说，男性不先查，就不要生孩子。万一男性精液有问题，在女性身上做的那些检查就毫无意义了。男性禁欲3-7天，把精液送到化验室分析一下。
**女性激素和排卵**
第三是查女性的内分泌和排卵。不排卵是女性不孕的主要原因之一。月经第三天抽血查激素，闭经的人如果子宫内膜厚度小于5mm可以随时查激素。月经第10-12天开始3-4次超声检查检测卵泡生长情况，能判断是否有排卵。
**输卵管**
第四做输卵管造影。月经干净3-7天做造影可以判断输卵管是否通畅。输卵管不通是女性不孕的第二大原因。

做这些检查一般在两个月内就能完成，所以对那些治了10多年还不知道自己什么原因不孕的我不太理解，毕竟不明原因不孕的人不多，这些人兜兜转转数年，这些检查居然一个都没有做。
