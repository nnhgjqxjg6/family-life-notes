# 我院男科团队的研究成果可以预测无精子症患者显微取精的成功概率

> 更新时间：2026-09-16 (UTC+8)

//  

我国目前育龄夫妇不育比例高达10-15%，由于男性因素导致的不育占50%，其中10%由非梗阻性无精子症（NOA）导致。**NOA的特征是由于睾丸精子发生受损，精液中无法获取精子。**然而幸运的是，由于睾丸中存在局灶生精，一些NOA患者可以通过显微取精手术（micro-TESE）获取睾丸内精子并结合辅助生殖技术，进而实现成功受孕的目的。

广东省生殖医院自2017年开展睾丸显微取精手术以来，取精成功率大约50%左右。虽然成功率已经非常高，因仍无法准确预测显微取精手术结局，许多本来有很高获得精子概率的无精子症患者，放弃了显微取精手术选择供精治疗。

我院男科研究团队一直致力于研究预测睾丸显微取精成功率的方法，团队成员张莹博士最新的研究成果**“一种基于精浆游离microRNAs高精度预测模型用于预测临床显微取精手术结局”**在Annals of Translational Medicine杂志发表。

本研究根据显微取精患者的手术结局及睾丸内生精状态，分为“优”、“中”、“差”三组，分别提取三组患者精浆总游离microRNAs，通过高通量小RNA测序（sRNA-seq）技术筛选了不同组患者精浆中的差异表达microRNAs，并通过多重逆转录定量聚合酶链反应（multiple RT-qPCR）确定了四个microRNAs（hsa-miR-34b-3p,hsa-miR-34c-3p,hsa-miR-3065-3p,hsa-miR-4446-3p）为潜在预测因子，基于此四个microRNAs的预测模型于评估睾丸内精子发生概率，同时还对该模型的预测准确率进行了独立的临床验证，证明模型具有较高的预测精度。

该研究成果正在申请专利，尽快进行临床转化， 将来NOA患者可以在手术前评估睾丸内生精状态，准确预测其显微取精手术成功率， NOA患者通过显微取精手术可以获得自己的生物学后代。
